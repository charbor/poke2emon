# Project: poke2emon

## Commits

- Make frequent, small, incremental semantic commits as you work
- Use conventional commit messages (feat:, fix:, chore:, refactor:, docs:, etc.)
- Do NOT include `Co-Authored-By` lines — no Claude credit in commits
- Commit after each meaningful change; don't batch unrelated changes

## Python Environment

- Use **pixi** for environment and dependency management
- Run commands via `pixi run` (e.g. `pixi run python`, `pixi run pytest`)
- Add dependencies with `pixi add <package>`
- Do not use pip, conda, venv, or virtualenv directly
